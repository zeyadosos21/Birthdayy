# Malookkyyy Birthday Site

A mobile-first private birthday memory site with:

- Private 4-digit lock screen
- Home page
- Gallery categories: All Memories, 21/6, 22/7, Gym, In Cairoo
- Photo + video lightbox
- Alternating Memories timeline
- Shared Notes area with To Do List + Wedding Songs
- Optional owner-only delete controls
- GitHub Pages hosting with Supabase used only for shared data

See `SETUP.md` before publishing.
